# 🎓 課程宣傳（Google Flow）｜附的技能怎麼用

> **主線不變：A 路 Google Flow 自動化**（`python tools/flow_ready.py` → `python tools/flow_run.py --dry` → 使用者說「開始出片」才 `python tools/flow_run.py` → `python tools/make_final.py`）。
> 下面的技能是用來把 Flow 拍好的片段**包裝得更專業**：片頭、資訊字卡、Logo 結尾、配樂。不可以拿它們取代 Flow、不可以改成手動流程。

| 技能 | 什麼時候用 | 產出放哪裡 |
|---|---|---|
| `skills/emotion-director/` | **出片前**：`--dry` 列出提示詞後，用它的鏡頭語言、情緒、動作寫法把每鏡提示詞改得更有電影感（只改提示詞、不改分鏡；先給使用者看） | 寫回 `影片需求.json` 的 `shots[].prompt` |
| `skills/promo-ad-forge/` | **片段到齊後**：做 3～5 秒動態片頭（課名大標）與結尾 CTA（日期、地點、報名網址），用 `templates/course-promo-16x9.html` 的主標幕／時間幕／CTA 幕改短版 | `03_字卡/片頭.mp4`、`03_字卡/片尾.mp4` |
| `skills/content-to-motion-video/` | 想要別的動畫風格（48 種組合）做片頭、重點字卡時；或幫 Flow 成片疊加標註字卡（模式 B） | 同上 |
| `skills/liang-cut-broll/` | 中間插一張「日期／地點／名額」資訊字卡；10 種廣播級風格 | `03_字卡/` |
| `skills/pixel2motion/` | `素材/` 有學校／單位 Logo 時，做 Logo 結尾動畫（可接在 CTA 前） | `03_字卡/片尾.mp4` 的一部分 |
| `skills/website-to-video/` | 選配：使用者有課程網站網址，想把網站畫面剪進宣傳片 | 片頭或片尾 |

## 建議順序
1. `python tools/flow_ready.py`（出片前檢查）→ `python tools/flow_run.py --dry`，把提示詞給使用者看；可先用 emotion-director 修飾提示詞（徵得同意）。
2. 使用者說「開始出片」→ `python tools/flow_run.py`（Flow 小幫手自動生成、自動核准、自動下載到 `片段/`）。
3. 等片段時（或片段到齊後）做包裝：片頭、資訊字卡、Logo 結尾 → 輸出 mp4，比例照 `output.ratio`，解析度與 Flow 片段一致（16:9＝1280×720 以上）。
4. 配樂：`素材/` 有使用者的 mp3 就用；沒有就用 `skills/promo-ad-forge/music-library/` 的 CC BY 曲（活潑 Wepa／溫暖 Carefree），複製成 `06_配樂/配樂_定稿.mp3`，並把那一首的標示文字存成 `06_配樂/標示作者.txt`。
5. `python tools/make_final.py` 合成（會自動接 `03_字卡/片頭.mp4`、`片尾.mp4`，配樂標示複製到 `成品/`）。

## 注意
- 畫面上的日期、價格、名額、網址**只能用使用者填的**，沒填就不放，不可自己編。
- 包裝片段的算圖只用本機 `npx -y hyperframes render`（免費）；不要用 `templates`、`reverse`、`media-use generate` 等付費指令。
- Flow 點數全部用完時，先照製作包 `SKILL.md` 問使用者要走 B 路（Gemini API）還是免費備援（promo-ad-forge 整支做動態廣告）。
