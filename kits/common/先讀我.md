# 先讀我｜這個製作包怎麼用

這個資料夾是從「影片製作包生成器」下載的，裡面有你填的影片內容，還有讓 AI 幫你做影片的說明書和工具。

## 1. 解壓縮
把 zip 按右鍵 →「解壓縮全部」，得到一個資料夾（就是你現在看到的這個）。

## 2. 在這個資料夾打開你的 AI
在資料夾空白處按右鍵 →「在終端機中開啟」，輸入下面其中一個，按 Enter：

| 你裝的是 | 輸入 |
|---|---|
| Claude Code | `claude` |
| Codex | `codex` |
| Antigravity | `agy` |

## 3. （只有 Google Flow 類要做，短影音跳過）裝一次「Flow 小幫手」
1. Chrome 網址列輸入 `chrome://extensions`，按 Enter。
2. 打開右上角「開發人員模式」。
3. 按「載入未封裝項目」，選這個資料夾裡的 `tools\Flow小幫手擴充`。
4. 打開 https://flow.google.com ，確認右上角是你要用的 Google 帳號。

（裝過就不用再裝。AI 操作 Flow 時分頁上方會出現「Flow 小幫手已開始對這個瀏覽器進行偵錯」，這是正常的。）

## 4. 跟 AI 說這一句
Google Flow 類（課程宣傳、校園形象、知識概念短片）會花點數，先叫 AI 檢查、不出片：
```
請先讀這個資料夾的「先讀我.md」和 SKILL.md，先做準備就好：檢查環境，告訴我用哪個 Google 帳號、今天剩幾點、每鏡大約幾點，再把每一鏡要送給 Flow 的提示詞列給我看；有角色的話，也告訴我角色設定圖要用什麼產生、大約花多少。先不要出片，等我說「開始出片」再開始。
```
看過提示詞沒問題，再說「提示詞沒問題，請開始出片，每完成一鏡就回報一次。」AI 會先列一個「要花點數，請確認」的框（第幾鏡、哪個帳號、預估幾點），你回「確認」它才會真的出片。（出片時不用開著生成器：AI 會自己接上 Flow 小幫手；只要 Chrome 開著、裡面有已登入的 Google Flow 分頁。）

出片路線選了 **FAL（付費，按秒計費）** 的人，不用 Google Flow、不用裝 Flow 小幫手（第 3 步可以跳過），改說：
```
請先讀這個資料夾的「先讀我.md」和 SKILL.md，先做準備就好：先幫我做出片前檢查，告訴我 FAL 金鑰能不能用、用哪個模型、每鏡幾秒、預估要花多少美元，再把每一鏡的提示詞列給我看；有角色的話，也告訴我角色設定圖要怎麼做、大約花多少。先不要出片，等我說「開始出片」再開始。
```
FAL 按秒扣你自己的 FAL 額度（Kling 每秒約 US$0.07、Wan 每秒約 US$0.05）。出片前 AI 會列「要花錢，請確認」的框（預估 US$ 多少），你回「確認」才會花錢；失敗不會自動重試。餘額和實際扣款到 https://fal.ai/dashboard 看。課程 U10B 有申請帳號、儲值、建立金鑰的完整教學。

短影音不花點數，可以直接說：
```
請先讀這個資料夾的「先讀我.md」和 SKILL.md，完全照裡面的步驟，幫我把這支影片做出來。每完成一鏡就用白話跟我回報。
```

## 5. 拿到成品
做好的影片在 `成品\` 資料夾，旁邊還有一份 `成片驗收報告.md`（解析度、片長、字幕、聲音、角色一致等檢查結果）。

## 想修改？
- 改某一鏡：「第 3 鏡太暗了，幫我重做第 3 鏡」
- 加配樂：建一個 `素材` 資料夾放一首 mp3（要有授權，例如 Pixabay Music 免費可商用），跟 AI 說「重新合成」。沒有自己的 mp3 時，AI 可能會用製作包內附的 CC BY 配樂（Kevin MacLeod），那就要照 `成品\配樂標示_貼到說明欄.txt` 在影片說明欄或片尾標示作者
- 改字幕：「把字幕第二句改成……，重新合成」

## 資料夾裡有什麼
| 檔案 | 用途 |
|---|---|
| `影片需求.json` | 你在生成器填的全部內容（AI 照這個做） |
| `分鏡表.md` | 好讀版分鏡表 |
| `帳號與金鑰.json` | （Google Flow 類才有）你填的帳號、密碼、金鑰（含 FAL 金鑰 falKey；**不要傳給別人、不要截圖**） |
| `SKILL.md` | 給 AI 的做事規範 |
| `tools\` | 出片、合成、檢查環境的工具 |
| `skills\` | 這個類別附的技能（片頭、字卡、結尾動畫、配樂、提示詞修飾等），清單見 `skills\風格說明.md` 或 `skills\技能說明.md` |
| `素材\` | （有上傳才有）你上傳的 Logo、參考圖；想加配樂就自己建這個資料夾，放一個 mp3 |
