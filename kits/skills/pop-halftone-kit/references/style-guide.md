# pop-halftone 風格指南

## 色票

| token | 色碼 | 用途 |
|---|---|---|
| `--pp-paper` | `#f3ead7` | 紙（亮場底色） |
| `--pp-ink` | `#1c1a1a` | 墨（主文字、描邊、硬陰影） |
| `--pp-red` | `#e23b2e` | 主強調、錯位紅版 |
| `--pp-yellow` | `#f2c230` | 暗場強調、視窗標題列 |
| `--pp-blue` | `#2c4fc4` | 錯位藍版、亮底次強調 |
| 暗場紙色 | `#231f1d` | 情緒低點場景（keys 裡設 `paper`） |

一場景只用 1 組調色盤（2–4 色），換場就換調色盤，形成節奏。

## 字

- 大字：Noto Sans TC 900，110–250px，`letter-spacing: -0.02em`，`.pp-title` 自帶錯位紅藍陰影。
- 一句只強調 1 個詞（`.pp-hl`），強調詞要是笑點或痛點。
- 數字／系統訊息：IBM Plex Mono Bold（`--pp-mono`），中文自動退回 Noto。

## 場景節奏（10 秒範本）

| 場 | 秒 | 敘事 | 道具 |
|---|---|---|---|
| 1 | 0–2.1 | 誘因（新東西來了） | 膠囊標籤 + 大字砸入 + 視窗卡 |
| 2 | 2.1–4.4 | 代價出現 | 老虎機價格 + 游標點升級 + 金幣雨 |
| 3 | 4.4–6.6 | 代價累積 | 三條洩光 + 開關被打開 |
| 4 | 6.6–8.4 | 失控（暗場） | 儀表爆表 + 螢幕震 |
| 5 | 8.4–10 | 反轉結論 | 兩行大字 + 吉祥物 + 印章 |

全片一條「持續上升的 HUD 數字」把各場串起來（範本是帳單）。

## 構圖

- 背景 `centerClear` 0.9 左右，大字區保持紙色；色團與網點集中在四周。
- 卡片：6px 墨框 + 10px 硬陰影，不用模糊陰影。
- 每場至少 1 個「會動的 UI 物件」當比喻，文字不要獨撐整場。

## 反諷寫作公式

誘因（變強了）→ 代價（掏錢）→ 累積（時間、精力）→ 失控（無止盡）→ 反轉（我更累）＋一個「系統很冷靜」的冷笑點（例如「已自動續訂」）。

## 60 秒版節奏（showcase-60s 範本）

12 場 × 5 秒，每場**一個主道具**＋一句大字，每 2 場換一次主題、每 10 秒放一次轉場：

| 秒 | 主題 | 道具 | 3D |
|---|---|---|---|
| 0–5 | riso | 翻牌看板 + 跑馬燈 | 寶石 float |
| 5–10 | riso | 打字框刪了重打 + 轉圈 | — |
| 10–15 | fluo | 吊牌改價 | 鈔票 rain |
| 15–20 | fluo | 收據列印 | 金幣 burst |
| 20–25 | sunset | 長條圖衝破 + 手繪圈 | — |
| 25–30 | sunset | 進度條卡 99% 歸零 | 沙漏 float |
| 30–35 | mint | 撕日曆 | 時鐘 orbit |
| 35–40 | mint | 待辦越做越多 + 刪改字 | — |
| 40–45 | newsprint | 通知轟炸 + 紅點 99+ | 文件 burst |
| 45–50 | newsprint 暗 | 沙漏翻轉 + 精力圓餅 | 咖啡杯 rain |
| 50–55 | riso 暗 | 倉鼠滾輪 | GPU orbit |
| 55–60 | riso | 結論大字 + 便利貼 | 混合 rain |

HUD 用兩條反向的數字（帳單↑、睡眠↓）把整支片串起來。

## 主題選用

| 主題 | 情緒 | 適合 |
|---|---|---|
| `riso`（預設） | 熱鬧、普普 | 開場、結論 |
| `fluo` | 刺眼、消費感 | 價格、帳單、促銷 |
| `sunset` | 焦躁、上升 | 成長曲線、等待 |
| `mint` | 假裝冷靜 | 日常、待辦、時間 |
| `newsprint` | 資訊過載、嚴肅 | 通知、新聞、暗場 |
