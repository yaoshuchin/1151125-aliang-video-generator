# 🎬 影片製作包生成器 · 視覺化旗艦版
> **我用 Skill 建置影片 · 阿亮老師（曾慶良）AI 影音實戰工作坊**

本專案為阿亮老師「影片製作包生成器」之現代化視覺增強典藏版。具備多主題分頁標籤切換、四色情境布景切換、三段字型等比縮放、磨砂玻璃門禁密碼認證，以及離線與 CDN 雙軌製作包打包下載系統。

---

## 🌟 核心特色功能

### 1. 🔒 磨砂玻璃門禁防護 (Password Gate)
- **通關密碼**：`nato`
- **安全標準**：採用瀏覽器原生 **Web Crypto API SHA-256** 雜湊計算，代碼中絕無明文密碼，符合全域資安防護規範。
- **認證記憶**：登入成功後自動記錄授權狀態，並支援右上角一鍵【登出鎖定】。

### 2. 🎨 四色布景與字型無障礙縮放
- **四色情境色彩切換**：
  - ☀️ **淺色明亮 (Light)**：雅致清爽公務簡報風格
  - 🌙 **科技深色 (Dark)**：星空夜間高對比防眩光
  - 🍃 **翡翠綠色 (Green)**：護眼茶園自然清新綠
  - 🌊 **海洋藍色 (Blue)**：俐落專業智慧科技藍
- **三段字級等比縮放**：
  - **中**（`16px`）：標準公務檢視
  - **大**（`18.5px`）：長者與行動裝置舒適閱讀
  - **特大**（`21.5px`）：遠距投影與輔助教學模式

### 3. 📑 視覺化五大功能分頁 (Tab Navigation)
1. 🚀 **生成器主控台 (Generator Console)**：完整的四步驟影片製作包生成流程（模式/引擎 ➔ 類別/風格 ➔ 內容填寫 ➔ 製作包下載）。
2. 🎨 **類別與風格圖鑑 (Style Gallery)**：卡片式視覺圖鑑，展示短影音 6 大風格（動態字卡快剪、知識圖解動畫、教學短講、Logo 動畫、實景素材快剪、手繪故事短片）及 Google Flow 3 大片型，支援「一鍵套用製作」。
3. 📽️ **經典分鏡範例庫 (Replays Showcase)**：可視化展示「成果展快訊」、「AI 工作坊招生」、「學校一天」、「颱風形成」四大真實案例的分鏡表、鏡頭景別、音效與提示詞，並可「一鍵載入生成器」。
4. 🛠️ **工具與串接中心 (Tools & Bridge Hub)**：下載本機 AI 串接包、下載 Flow 小幫手 Chrome 擴充套件、九大素材遙控器使用說明、出片環境檢測指令清單及 8899 埠連線即時測試。
5. 📖 **全流程操作手冊 (Workflow SOP)**：完整解析三層架構（生成器 ➔ AI 助教 ➔ 遙控器）、給 AI 的一句話神級指令、15 分鐘極速出片實戰步驟與成片驗收檢核表。

## 🚀 本機快速啟動

本專案為純前端單頁應用程式（SPA），無需後端資料庫：

```bash
# 使用 Python 內建伺服器啟動
python -m http.server 8080

# 瀏覽器開啟：
http://localhost:8080
```
